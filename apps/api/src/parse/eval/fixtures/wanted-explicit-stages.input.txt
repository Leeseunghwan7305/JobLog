# 온라인 K-POP 트레이닝 프론트엔드(React) 개발자

회사명: 카운터컬쳐컴퍼니(킨즈아카데미)
직무: 온라인 K-POP 트레이닝 프론트엔드(React) 개발자
경력: 3-10년
근무지: 서울 성동구 성수일로1길 1
마감일: 2024.12.30

## 포지션 상세

저희 카운터컬처는 KPOP 인재의 성장을 이끄는 팀으로, 20명 이하 소수정예로 KPOP 시장 내의 임팩트를 만들고자 합니다.

## 주요업무

- 웹 기반 온라인 교육 매니지먼트 시스템(Online Learning Management System) 구축
- 영상 기반 Contents Delivery 서비스 제작 (HLS 스트리밍, 자막·더빙, 피치/배속 제어)
- 실시간 비디오 채팅 서비스 제작 (ZoomVideoSDK 기반)
- React 기반 백오피스 어드민 페이지 제작

## 전형절차

1. 지원서 심사: 지원 파트 역량을 보기 위한 직무 테스트가 있습니다. 서류 심사보다 높은 비중을 갖습니다.
2. 직무 인터뷰 : 같이 일하실 분과 진행 합니다!
3. 문화 적합성 인터뷰 : 면접 소그룹을 만들어서 진행합니다. 경영진 인터뷰를 포함합니다.
4. 최종 합격

## 자격요건

- React, Rest API 작업 환경에 익숙하신 분
- Tailwind css 를 1년 이상 사용해보신 분
- 최소 3년 이상의 프론트엔드 커리어를 가지고 계시는 분
